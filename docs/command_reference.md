## Command Patterns and Variations

### Natural Language Flexibility

Wizard understands various ways to express the same command:

**Timer Examples:**
- "Set a timer for 5 minutes"
- "Timer 5 minutes"
- "Remind me in 5 minutes"
- "5 minute timer"

**Volume Examples:**
- "Turn the volume up"
- "Make it louder"
- "Increase volume"
- "Volume up"

**File Operations:**
- "Open my documents"
- "Show me documents"
- "Go to documents folder"
- "Documents"

### Command Chaining

Some commands can be combined:
- "Open Chrome and go to Google"
- "Set volume to 50 and play music"
- "Create folder Projects and open it"

### Context Awareness

Wizard remembers context within conversations:
- "Open Calculator" → "What's 15 times 23?" (uses calculator)
- "Find my presentation" → "Open it" (opens found file)
- "Set timer for 10 minutes" → "Cancel it" (cancels the timer)

### Error Handling

When commands aren't understood:
- Wizard will ask for clarification
- Suggests similar commands
- Provides help for command categories

**Examples:**
```
You: "Open Photoshop"
Wizard: "I couldn't find Photoshop. Did you mean Paint or GIMP?"

You: "Play that song"
Wizard: "Which song would you like me to play? Please be more specific."
```

## Command Tips

### Best Practices

1. **Be Specific**: Use exact application names when possible
2. **Natural Speech**: Speak naturally, don't use robotic commands
3. **Wait for Response**: Let Wizard finish before the next command
4. **Use Context**: Reference previous commands when relevant
5. **Learn Patterns**: Notice which phrasings work best for you

### Common Shortcuts

- "Time?" instead of "What time is it?"
- "Weather?" instead of "What's the weather like?"
- "News?" instead of "What's the latest news?"
- "Calculator" instead of "Open Calculator"

### Troubleshooting Commands

If a command doesn't work:
- Try rephrasing it
- Be more specific
- Check if the application/file exists
- Use the help command: "Help with [category]"
